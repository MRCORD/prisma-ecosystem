# Visual Coherence System - Prisma Community Events

## Brand Identity Foundation

### **Prisma Color Palette**
- **Primary Black**: #000000 (sophistication, premium positioning)
- **Prisma Cyan**: #47FFBF (innovation, energy, tech-forward)
- **Prisma Purple**: #8376FF (creativity, intelligence, premium)
- **Prisma Pink**: #FF48C7 (boldness, differentiation, vibrancy)
- **Support White**: #FFFFFF (clarity, space, elegance)

### **Color Psychology & Application**
- **Black**: Foundation color para sophistication y premium experience
- **Cyan**: Accent para innovation y AI-forward positioning  
- **Purple**: Secondary accent para creativity y strategic thinking
- **Pink**: Highlight color para key moments y differentiation
- **White**: Space y clarity para readability y elegance

## Visual Hierarchy System

### **Typography Standards**

#### **Primary Typeface: Inter**
- **Rationale**: Modern, tech-forward, excellent readability
- **Usage**: All body text, descriptions, practical information
- **Weights**: Light (300), Regular (400), Medium (500), Bold (700)

#### **Display Typeface: Custom Prisma Display**
- **Rationale**: Unique brand expression para headlines
- **Usage**: Event titles, key messaging, hero statements
- **Characteristics**: Geometric, slightly futuristic, confident

#### **Monospace: JetBrains Mono**
- **Rationale**: Tech credibility, code/framework references
- **Usage**: Technical content, code examples, data displays
- **Application**: Framework names, metrics, technical specifications

### **Layout Principles**

#### **Golden Ratio Application (1.618)**
- **Spacing ratios**: All margins y padding follow golden ratio proportions
- **Content hierarchy**: Title sizes, image proportions, section breaks
- **Visual balance**: Element positioning y white space distribution

#### **Grid System: 12-Column Foundation**
- **Desktop**: 12 columns con 24px gutters
- **Tablet**: 8 columns con 20px gutters  
- **Mobile**: 4 columns con 16px gutters
- **Consistency**: All materials follow same grid system

## Brand Application Guidelines

### **Logo Usage Standards**

#### **Minimum Sizes**
- **Digital**: 120px width minimum
- **Print**: 1 inch width minimum  
- **Signage**: Visible from 10 feet minimum
- **Merchandise**: Proportional to item size

#### **Clear Space Requirements**
- **All directions**: Minimum 2x logo height
- **Background interactions**: High contrast maintenance required
- **Color variations**: Black, white, y single color versions
- **Prohibited uses**: No stretching, rotating, or color modifications

### **Color Combination Rules**

#### **Primary Combinations**
- **Black + Cyan**: Tech innovation emphasis
- **Black + Purple**: Creative strategy focus
- **Black + Pink**: Differentiation y energy
- **White + any Prisma color**: Clean, professional alternative

#### **Secondary Combinations**
- **Cyan + Purple**: Innovation + creativity
- **Purple + Pink**: Strategic boldness  
- **All three colors**: Full brand expression (use sparingly)

#### **Forbidden Combinations**
- **Low contrast pairings**: Cyan on white, purple on black
- **Overuse**: More than 2 Prisma colors simultaneously
- **Competing colors**: Any non-Prisma colors mixed with brand palette
